What the radio is doing

One radio, so one job at a time. As a client it joins a network and that is the board's way out — the tunnel rides on it. As an access point it becomes a network for the wall tablet, and there is no uplink at all, which is the normal state at a site with no internet.

Trigger sweep

{% if sys_msg %}
{{ sys_msg }}
{% endif %} {% if sys_err %}
{{ sys_err }}
{% endif %}

When triggered, the camera can swing between two saved views to cover a scene wider than one shot. Aim with the D-pad and save the ends with Set Left / Set Right on the panel; there are no angles to type because this camera does not report them.

Slower is gentler on the motors and gives a sharper picture at each end; faster spends less time in transit.

A rolling hour, so repetition cannot wear the dome out over a season. Each move between two points is charged about three seconds, so 600 allows roughly twenty minutes of sweeping an hour. Set too low and a long incident spends it all and later ones get no sweep at all. Coming home is always allowed, whatever is left.
